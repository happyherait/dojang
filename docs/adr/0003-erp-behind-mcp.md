# ADR 3: 업무 시스템을 MCP 서버로 분리한다

## 상황

에이전트 코드가 ERP 데이터베이스에 직접 접근하면 권한 검사와 감사가 에이전트 안에 섞입니다. 레거시 시스템을 붙일 때마다 연동 코드도 새로 작성해야 합니다.

## 결정

ERP 기능을 표준 MCP 서버로 노출하고, 에이전트는 MCP 클라이언트로 호출합니다.

- 요청마다 사용자 권한의 짧은 JWT로 호출합니다. 에이전트 전용 만능 계정을 두지 않습니다.
- 서버는 토큰의 직급을 믿지 않고 현재 사용자 정보를 다시 읽습니다.
- `readOnlyHint`가 있는 도구만 모델에 제공합니다. 쓰기 도구는 기본적으로 차단됩니다.
- 쓰기 도구의 최종 검증은 MCP 서버 안에서 수행합니다. 에이전트가 우회되어도 검증은 남습니다.

## 결과

Claude Code 같은 다른 MCP 클라이언트도 같은 도구와 권한 규칙을 사용합니다. MCP Inspector로 에이전트 없이 시험할 수도 있습니다.

대신 호출마다 네트워크 왕복이 생기고, 프로세스가 하나 늘어납니다. 프로토타입이라 연결을 호출마다 새로 만들며, 운영에서는 재사용을 검토해야 합니다.
